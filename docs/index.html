今日の空気

表米連邦官報が計算資源の先物・金融派生商品（デリバティブ）契約に関する意見公募を開始し、Anthropicは独自の検索基盤をゼロから構築する専任エンジニアの採用へ着手した。同時に推論市場では、OpenRouter上でQwen3.8 27Bが49%値下げ、DeepSeek V4 Flashが40%値下げされる一方、高負荷なDeepSeek V4 Proが88%値上げされる極端な価格分離が発生した。

裏OpenRouterで起きたQwenとDeepSeekの4割超の一斉値下げとProモデルの88%サージ価格設定は、プロバイダーによる意図的な選別構造の完成を意味する。計算リソース先物化で原価ヘッジを進める資本側に対し、推論インフラ側は一次処理を限界費用ゼロへ叩き落として競合を締め出し、難易度の高い最終推論から超過利潤を吸い上げる体制を固めた。個人開発者がフラッグシップモデルを常時直叩きする設計は、今日を境に純粋な資本流出の欠陥アーキテクチャへ転落したと見る。

退けた説 Flashモデルの値下げは単なる一時的な余剰サーバーの投げ売りであり、数日以内に元の価格帯へ戻るという仮説を検討したが、QwenとDeepSeekの双方が同時期に40%以上の値下げを一斉に実施していることから、競合排除を狙った恒久的な価格破壊競争であると判断し退けた。

参謀の勘

Anthropicの検索専任エンジニア採用が開始されたが、この種の基幹インフラ構築には通常半年以上の開発サイクルを要する基準率を踏まえると、Anthropicが今後30日以内に自社開発インデックスに基づく独自のWeb検索機能をClaude公式機能として一般公開する目は五分に満たないと見る。

根拠 求人票に検索基盤を「ゼロから（from the ground up）」立ち上げると明記されており、基盤開発の初期フェーズであることが確認できるため。

外れるとすれば Anthropicが既に裏で水面下の開発を完了させており、採用はリリース後の運用保守・スケール要員確保に過ぎない場合は早期発表があり得る。

確度 88%（独立見積り 88%・88%・3% の中央値） 3つの立場が割れた(票の幅0.85)ので中央値を採った。
