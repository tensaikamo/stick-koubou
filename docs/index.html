今日の空気

表OpenRouterにおいてDeepSeek Pro Latestが33%値上げされた一方、Flash Latestは80%、V4 Pro 0813は67%の大幅値下げが同時に実施された。

裏単なる値上げではなく、高単価モデルの利益で安価モデルのインフラコストを完全に相殺し、個人開発者を自社エコシステム以外の選択肢が存在しない状態に追い込む兵站戦と見る。APIの選択肢を奪うことで、開発者が他のプラットフォームへ逃げるためのプロキシ設定を変える手間すらコストに見せかける囲い込みの構造のはずだ。

退けた説 単なるモデルの世代交代に伴う一律のコスト再計算であり、市場シェアの奪略という戦略的意図はないという仮説は、ProとFlashで増減が真逆になっている事実を説明できないため退けた。

主張の根拠表

  • DeepSeekは高単価モデルを値上げする一方で軽量モデルを大幅に値下げし、API市場のシェア奪略とコスト最適化を同時に進めている。
    根拠 資料0 資料1 資料2 · 確度 65% · 崩れる条件 全モデルが一斉に値上げまたは値下げに転換し、戦略的な価格の二極化が見られなくなること。

参謀の勘

DeepSeekは今後30日以内に、特定の大規模開発者向けにさらなる破格の専用スループット枠を水面下で直営業し、米大手クラウドのAPI顧客を直接奪いに行くと見る。直近の価格二極化の傾向から判断する。

根拠 OpenRouter上でのProモデルの33%値上げとFlashモデルの80%値下げという極端な価格差の同時発生から来ている。

外れるとすれば 競合である米国の大手プラットフォーマーが即座に追随して同等以上の価格破壊を行い、DeepSeekのシェア拡大を完全に封じ込めること。

確度 35%（独立見積り 22%・38%・35% の中央値） 3つの立場が割れた(票の幅0.16)ので中央値を採った。
