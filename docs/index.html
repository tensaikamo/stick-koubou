表APIプラットフォームのOpenRouterにおいて、DeepSeekの主要モデル群の価格が極端に二極化する改定が行われた。DeepSeek Pro LatestおよびV4 Proが157%値上げされた一方、新型のDeepSeek V4.1 Flashは83%値下げ、バッチ処理も55%値下げされた。
